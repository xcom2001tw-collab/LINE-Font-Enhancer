# Security & Privacy｜安全性與隱私權聲明

## 安全性設計

LINE Font Enhancer 是一款獨立開發的非官方免費工具，旨在透過 FreeType 改善 LINE 電腦版的文字渲染品質。

- 不修改 LINE 原始執行檔及 DLL。
- 不讀取或蒐集使用者聊天內容。
- 不蒐集使用者個人資料。
- 不植入廣告或使用者追蹤程式。
- 不需要連線至外部伺服器即可運作。
- 提供原始碼供公開檢視。
- 提供 SHA-256 檔案完整性校驗值。
- 提供原廠設定還原功能。

## 執行檔與相容性

目前版本為公開測試版，尚未取得數位簽章，也尚未經過獨立第三方安全稽核。使用者應從本專案的 GitHub Releases 頁面下載，並可自行核對 SHA-256 校驗值。

不同 Windows 版本、LINE 版本及顯示環境可能影響相容性。

## 問題回報

若發現安全性問題或異常行為，歡迎透過 GitHub Issues 回報一般問題。請勿公開個人資料、聊天紀錄或可被利用的安全漏洞細節。

## Security Design

LINE Font Enhancer is an independent, unofficial freeware utility designed to improve LINE Desktop text rendering using FreeType.

- Does not modify LINE executables or DLLs.
- Does not read or collect chat messages.
- Does not collect personal information.
- Contains no advertisements or tracking components.
- Operates offline without requiring external servers.
- Provides publicly available source code.
- Provides SHA-256 checksums for file integrity verification.
- Supports restoring the original configuration.

## Binary Integrity and Compatibility

The current release is a public preview. It is not digitally signed and has not undergone an independent third-party security audit.

Users should download the utility from this project's GitHub Releases page and verify its SHA-256 checksum.

Compatibility may vary depending on Windows versions, LINE versions and display environments.

## Reporting Issues

General issues may be reported through GitHub Issues. Please do not disclose personal information, chat records or exploitable vulnerability details publicly.
